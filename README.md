# Cascade Wars

## Cascade Wars

Стратегическая игра для двух игроков: **X** и **O**.

### Старт партии

1. При включённом свободном расположении игроки по очереди тайно выбирают стартовую клетку на поле заданного размера (по умолчанию 20 × 20). После выбора X передаёт устройство игроку O; координаты скрыты.
2. При свободном выборе, если стартовые клетки совпали, оба игрока выбирают заново. Игра показывает сообщение **«Была выбрана идентичная позиция»**. После трёх совпадений подряд позиции автоматически размещаются в случайной паре противоположных углов.
3. Соседние стартовые клетки допустимы. Стартовое соприкосновение само по себе не запускает цепную реакцию.

### Правила игры

1. Первым ходит игрок **X**. Стандартное время — **3+10**: по 3 минуты каждому и добавка 10 секунд после завершённого хода.
2. За ход игрок выставляет заданное в настройках количество фигур (по умолчанию **три**). Каждая новая фигура должна соединяться со своей основной цепочкой по вертикали, горизонтали или диагонали; можно продолжать цепочку фигурами, поставленными в этом же ходу.
3. Если поставленная фигура соприкасается с фигурой противника, начинается **цепная реакция**. Уничтожаются только фигуры противника: задетая фигура и фигуры противника, непосредственно прилегающие к ней по вертикали, горизонтали и диагонали. Реакция затрагивает только первый слой; фигура, вызвавшая соприкосновение, остаётся на поле.
4. Если одновременно задеты несколько фигур, реакция сначала начинается с фигур, расположенных по горизонтали или вертикали, затем с диагональных.
5. После уничтожения клетка становится недоступной для дальнейших ходов.
6. Игрок, который не может поставить всё заданное количество фигур за ход, проигрывает.

### Запуск

В корневой папке проекта выполните команду go run . Затем откройте в браузере http://localhost:3000.

## Архитектура проекта

- `main.go` раздаёт браузерные файлы на `http://localhost:3000`.
- `ui/game.js` содержит состояние партии и правила: выбор старта, допустимые ходы, цепную реакцию и определение победителя. Модуль не работает с DOM.
- `ui/script.js` связывает игровой модуль с браузером: рисует поле, обновляет подсказки и обрабатывает действия игроков.
- `ui/index.html` содержит структуру страницы, а `ui/style.css` — её оформление.

## Работа с Git

- `main` — стабильная ветка; новые изменения начинаются от неё в отдельной ветке.
- Для задачи создаётся ветка `codex/<короткое-название>`, например `codex/refactor-game-architecture`.
- Изменения коммитятся в рабочую ветку и после просмотра вливаются в `main`. Незавершённая работа в `main` не попадает.

### Настройки партии

В окне настроек можно выбрать ширину и высоту поля отдельно (от 10 до 50 клеток; по умолчанию 20 × 20), число фигур за ход (от 1 до одной десятой площади поля, с округлением вниз до целого) и способ старта. Стандартный контроль времени — 3+10: три минуты каждому и десять секунд добавки после полного хода. Контроль времени можно отключить или изменить. При свободном расположении игроки тайно выбирают стартовые клетки; если оно отключено, игра ставит их в противоположные углы.

Случайные события можно включить в настройках партии и выбрать один из четырёх режимов появления: стандартный (30% на один предмет за завершённый ход), каскадный, адаптивный или гибридный. Фиксированного ограничения в три предмета на карте нет; новые предметы появляются на доступных клетках. При включённом сроке жизни предметы на поле исчезают после заданного числа завершённых ходов; по умолчанию они бессрочные. Подберите предмет, поставив фигуру на его клетку. Инвентарь хранит до трёх способностей; если он заполнен, новая способность заменяет самую старую.

В меню также есть каталог открытых и закрытых комнат. Открытые партии можно наблюдать, не занимая игровое место; зритель не может отправлять игровые команды.

- **Бомба** — в любой момент своего хода выберите её значок под именем игрока, затем наведите курсор на верхнюю левую клетку области 2×2 и нажмите. Область подсвечивается красным. Бомба очищает все четыре клетки: фигуры и заблокированные клетки исчезают, клетки снова доступны. Использование бомбы не расходует фигуры хода.
- **Свободное расположение** — выберите значок и поставьте дополнительную фигуру на любую пустую клетку. Она не заменяет и не расходует ни одну из фигур, обязательных для хода.
- **Дополнительный ход** — способность срабатывает автоматически после завершения текущего хода и даёт игроку ещё один полный ход.
- **Анти-бомба** — выберите любую область 2×2 в свой ход. Она уничтожает фигуры и превращает все четыре клетки, включая ранее заблокированные, в мёртвые блоки.
- **Призыв обломков** — выберите три клетки без фигур. Они становятся мёртвыми блоками; постановка обломков не расходует фигуры хода.
- **Щит** — выберите три свои фигуры. Они защищены от вражеского касания до начала вашего следующего хода. Бомба и анти-бомба пробивают защиту.
- **Генгста-Щит** — выберите свою фигуру, чтобы защитить её от вражеских касаний до конца партии. Бомба и анти-бомба пробивают защиту.
