# Viruses-Infection-Strategy

## Игра «Вирусы»

Стратегическая игра для двух игроков: **«Х»** и **«О»**.

### Старт партии

1. При включённом свободном расположении игроки по очереди тайно выбирают стартовую клетку на поле заданного размера (по умолчанию 15 × 15). После выбора «Х» передаёт устройство игроку «О»; координаты скрыты.
2. При свободном выборе, если стартовые клетки совпали, оба игрока выбирают заново. Игра показывает сообщение **«Была выбрана идентичная позиция»**. После трёх совпадений подряд позиции автоматически размещаются в случайной паре противоположных углов.
3. Соседние стартовые клетки допустимы. Стартовое соприкосновение само по себе не запускает цепную реакцию.

### Правила игры

1. Первым ходит игрок **«Х»**.
2. За ход игрок выставляет заданное в настройках количество фигур (по умолчанию **три**). Каждая новая фигура должна соединяться со своей основной цепочкой по вертикали, горизонтали или диагонали; можно продолжать цепочку фигурами, поставленными в этом же ходу.
3. Если поставленная фигура соприкасается с фигурой противника, начинается **цепная реакция**. Уничтожаются только фигуры противника: задетая фигура и фигуры противника, непосредственно прилегающие к ней по вертикали, горизонтали и диагонали. Реакция затрагивает только первый слой; фигура, вызвавшая соприкосновение, остаётся на поле.
4. Если одновременно задеты несколько фигур, реакция сначала начинается с фигур, расположенных по горизонтали или вертикали, затем с диагональных.
5. После уничтожения клетка становится недоступной для дальнейших ходов.
6. Игрок, который не может поставить всё заданное количество фигур за ход, проигрывает.

### Запуск

В корневой папке проекта выполните команду go run . Затем откройте в браузере http://localhost:3000.

## Архитектура проекта

- `main.go` раздаёт браузерные файлы на `http://localhost:3000`.
- `ui/game.js` содержит состояние партии и правила: выбор старта, допустимые ходы, цепную реакцию и определение победителя. Модуль не работает с DOM.
- `ui/script.js` связывает игровой модуль с браузером: рисует поле, обновляет подсказки и обрабатывает действия игроков.
- `ui/index.html` содержит структуру страницы, а `ui/style.css` — её оформление.

## Работа с Git

- `main` — стабильная ветка; новые изменения начинаются от неё в отдельной ветке.
- Для задачи создаётся ветка `codex/<короткое-название>`, например `codex/refactor-game-architecture`.
- Изменения коммитятся в рабочую ветку и после просмотра вливаются в `main`. Незавершённая работа в `main` не попадает.

### Настройки партии

В окне настроек можно выбрать ширину и высоту поля отдельно (от 10 до 50 клеток), число фигур за ход (от 1 до одной десятой площади поля, с округлением вниз до целого) и способ старта. Контроль времени можно отключить; при включённых часах задаются минуты на игрока и добавка за полный ход. При свободном расположении игроки тайно выбирают стартовые клетки; если оно отключено, игра ставит их в противоположные углы.

Случайные события можно включить в настройках партии. В начале игры появляется один предмет, затем после каждого полного хода новый предмет может появиться с вероятностью 30%; одновременно на поле находится не больше трёх предметов. Чтобы подобрать предмет, поставьте фигуру на его клетку. В инвентаре игрока хранится до трёх способностей; если он заполнен, новая способность заменяет самую старую.

- **Бомба** — выберите её значок под именем игрока, затем наведите курсор на верхнюю левую клетку области 2×2 и нажмите. Область подсвечивается красным. Бомба очищает все четыре клетки: фигуры и заблокированные клетки исчезают, клетки снова доступны. Использование бомбы не расходует фигуры хода.
- **Свободное расположение** — выберите значок и поставьте одну фигуру на любую пустую клетку. Эта фигура засчитывается в число фигур текущего хода.
- **Дополнительный ход** — способность срабатывает автоматически после завершения текущего хода и даёт игроку ещё один полный ход.
