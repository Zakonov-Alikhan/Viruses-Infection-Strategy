# Viruses-Infection-Strategy

## Игра «Вирусы»

Стратегическая игра для двух игроков: **«Х»** и **«О»**.

### Старт партии

1. Игроки по очереди тайно выбирают по одной стартовой клетке на поле 15 × 15. После выбора «Х» передаёт устройство игроку «О»; стартовые координаты не показываются.
2. Если выбранные клетки совпали, оба игрока выбирают заново. Игра показывает сообщение **«Была выбрана идентичная позиция»**. После трёх совпадений подряд позиции автоматически размещаются в случайной паре противоположных углов.
3. Соседние стартовые клетки допустимы. Стартовое соприкосновение само по себе не запускает цепную реакцию.

### Правила игры

1. Первым ходит игрок **«Х»**.
2. За ход игрок выставляет **три фигуры**. Каждая новая фигура должна соединяться со своей основной цепочкой по вертикали, горизонтали или диагонали; можно продолжать цепочку фигурами, поставленными в этом же ходу.
3. Если поставленная фигура соприкасается с фигурой противника, начинается **цепная реакция**. Уничтожаются только фигуры противника: задетая фигура и фигуры противника, непосредственно прилегающие к ней по вертикали, горизонтали и диагонали. Реакция затрагивает только первый слой; фигура, вызвавшая соприкосновение, остаётся на поле.
4. Если одновременно задеты несколько фигур, реакция сначала начинается с фигур, расположенных по горизонтали или вертикали, затем с диагональных.
5. После уничтожения клетка становится недоступной для дальнейших ходов.
6. Игрок, который не может поставить все три фигуры за ход, проигрывает.

### Запуск

В корневой папке проекта выполните команду go run . Затем откройте в браузере http://localhost:3000.

## Архитектура проекта

- `main.go` раздаёт браузерные файлы на `http://localhost:3000`.
- `ui/game.js` содержит состояние партии и правила: выбор старта, допустимые ходы, цепную реакцию и определение победителя. Модуль не работает с DOM.
- `ui/script.js` связывает игровой модуль с браузером: рисует поле, обновляет подсказки и обрабатывает действия игроков.
- `ui/index.html` содержит структуру страницы, а `ui/style.css` — её оформление.

## Работа с Git

- `main` — стабильная ветка; новые изменения начинаются от неё в отдельной ветке.
- Для задачи создаётся ветка `codex/<короткое-название>`, например `codex/refactor-game-architecture`.
- Изменения коммитятся в рабочую ветку и после просмотра вливаются в `main`. Незавершённая работа в `main` не попадает.
