# Viruses-Infection-Strategy

## Игра «Вирусы»

Стратегическая игра для двух игроков: **«Х»** и **«О»**.

### Правила игры

1. Первым ходит игрок **«Х»**.
2. Игроки совершают ходы с противоположных краёв игрового поля.
3. За один ход игрок выставляет **три фигуры**. Новые фигуры должны соединяться с основной цепочкой по вертикали, горизонтали или диагонали.
4. Если фигура соприкасается с фигурой противника по вертикали, горизонтали или диагонали, начинается **цепная реакция**: уничтожается фигура противника и первые прилегающие к ней фигуры по вертикали, горизонтали и диагонали.
5. Если одновременно соприкасаются несколько фигур противника, цепная реакция начинается с фигур, расположенных по горизонтали или вертикали.
6. После уничтожения клетка, которую занимала фигура противника, становится недоступной для дальнейших ходов.
7. Игра продолжается, пока у противника остаётся возможность совершить ход.
